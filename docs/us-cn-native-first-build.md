# Optional US Chinese native-text build

This opt-in pipeline starts with the authenticated English ROM, parses the
separately supplied translated ROM, serializes native text tokens, and links new
text addresses. It does not copy the translated image or import its engine hooks.
The English profile returns the exact original English image.

All ROMs, extracted tokens, fonts, patches and captures remain in explicitly
selected external directories. Do not upload these resources. This tooling is an
isolated source snapshot because the supplied resource-tool directory had no Git
metadata; it does not modify that directory or the engine's selected manifest.

## Reproduction

Select the compatible engine format library explicitly:

```sh
export FFTA_DECOMP_ROOT=/explicit/decomp/checkout
python3 tools/analyze_us_cn_rom.py --retail "$US_ROM" \
  --translated "$CN_ROM" --output-dir "$EVIDENCE/inventory"
python3 tools/import_us_cn_native.py --retail "$US_ROM" \
  --translated "$CN_ROM" --output-dir "$EVIDENCE/import"
python3 tools/build_us_cn_native.py --retail "$US_ROM" \
  --translated "$CN_ROM" --bundle "$EVIDENCE/import/native-import-bundle.json" \
  --language zh --output-dir "$EVIDENCE/zh"
python3 tools/validate_us_cn_native.py --image "$EVIDENCE/zh/ffta-zh.gba" \
  --bundle "$EVIDENCE/import/native-import-bundle.json" \
  --report "$EVIDENCE/zh/build-report.json" --output "$EVIDENCE/linked-check.json"
python3 tools/build_us_cn_native.py --retail "$US_ROM" \
  --language en --output-dir "$EVIDENCE/en"
```

Repeat import and linking into two clean directories; compare bundle, image and
report hashes. The English image must equal the retail input byte for byte.
No compiler, ROM upload, network lookup or upstream repacker is required.

## Address and format rules

| Family | Lookup retained | Build-time relocation |
| --- | --- | --- |
| Scene | Original master table, 32-bit master-relative offsets | Page-relative 16-bit entry offsets; nested page 61 uses another master-relative table |
| Fixed | Original master table, absolute 32-bit page pointers | Page-relative 16-bit entry offsets |
| Word tables | Original table address and all consumer aliases | Original pointer slots updated to appended native token payloads |
| Font | Original glyph and advance addresses | Authenticated source glyph cells and advances copied as paired resources |

The first page-relative entry offset remains `(count + 1) * 2`; the extra slot
is retained as an end sentinel. Pages must remain below 64 KiB. Appended resources
begin after the complete 16 MiB baseline, within the GBA 32 MiB ROM window. The
output is padded to 32 MiB. No supposedly unused retail filler is overwritten.
Existing compressed source records are decoded and serialized as native raw
records with only the compression bit cleared. Alternate encoding, all other
flags, variable/name tokens, choices, line and page controls remain intact.

Text IDs are stable; linked addresses are generated by the build. Item/ability
IDs are unrelated to glyph assignments and are not remapped. Runtime language
switching is not implemented; `--language` selects the build profile.

## Evidence and limits

The first importer covers 123 complete groups and 15,201 text IDs. Scene page 31
has only 23 valid Chinese pointers; its final two English entries are proven
alternate-encoding close controls (`flags 0x11`, bytes `8A FF`) without glyphs.
Only those exact placeholders may fall back to retail. A general missing-text
fallback is refused. The linked validator follows every actual root and entry
pointer and checks the decoded payload against the authenticated import.

Preserving the original word table address is essential: the battle table has
many real consumer aliases. Replacing one literal root does not update all
menus. The first prototype exposed this error at runtime; the released design
updates table entries in place and leaves consumer instructions unchanged.

The supplied translated ROM also has separate display/startup, uncompressed-copy
and resource-overlay hooks. They are analyzed separately and excluded from this
native-text build. Original graphics, untranslated consumer text and those
optional overlays remain retail. This is a first playable Chinese text build,
not a claim that every original translation asset or game path is covered.

The translated font's native glyph codes are preserved. The available upstream
Unicode charset does not match this ROM and must not be silently substituted.
A verified editable Unicode dictionary and arbitrary new-character assignment
remain separate work. Glyph/token byte round trips do not establish Unicode
semantics, full-game layout quality or physical hardware acceptance.
